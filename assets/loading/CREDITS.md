The original SVG paths and colours are unchanged. The optional Jellyfin loading animation applies gentle CSS movement and opacity to the complete icon. It identifies the Jellyfin server being loaded; it is not ScreenHarbour’s logo. Jellyfin does not publish or endorse ScreenHarbour.

The remaining loading illustrations are original ScreenHarbour CSS artwork.
