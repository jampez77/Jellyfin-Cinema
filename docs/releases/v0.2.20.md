# Jellyfin Cinema 0.2.20 — prerelease

Cached Home returns now reveal Jellyfin's native rows, streaming services and collection rows together. Cinema still reuses loaded data immediately, but waits for the native Home layout to settle before revealing the page, so custom rows cannot appear ahead of the rest of Home.

Background settings and content refreshes do not delay the cached page. Return visits still skip the cinema animation; the first load keeps it. Cached native rows normally need only the existing brief frame-settlement check. An unusually slow native rebuild retains the existing bounded fallback.

## Installation

Update from the existing Cinema catalogue, restart Jellyfin, then reload desktop Jellyfin and fully close/reopen the TV app.

## Validation

- TypeScript, all 176 unit/API tests and 66 affected browser tests passed.
- Browser regression samples rendered frames while native Home is delayed and verifies that native and cached custom rows reveal together, without mounting an animation or waiting for held background refresh requests.
- No server behaviour changed. Packages are built for all three supported Jellyfin targets. The new build has not been installed or tested on the physical Mac mini/LG TV during development.
