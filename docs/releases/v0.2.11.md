# Jellyfin Cinema 0.2.11 — prerelease

Custom collection rows now fit into Home’s loading and card styling. Install from the Jellyfin Cinema catalogue or the [v0.2.11 release assets](https://github.com/jampez77/Jellyfin-Cinema/releases/tag/v0.2.11), following the [installation guide](../server.md).

## Changes

- Initial collection rows wait for Jellyfin’s native Home sections to settle before appearing in their saved positions. A bounded fallback prevents stalled native loading from hiding collections indefinitely. Existing rows stay visible while a background refresh prepares replacements.
- Collection rows use the same section spacing as native Home rows, with less excess padding and aligned headings.
- Horizontal scrollbars are hidden. Rows still scroll with the remote, keyboard, mouse and touch controls.
- Focus borders surround the thumbnail on both native and custom cards. Titles and ranked number images stay outside the border, and scroll gutters leave room for the highlight on the first and last item.
- The collection editor preview shares the updated card styling. Home sync failures continue to retry quietly.

## After installing

Restart Jellyfin, then reload the desktop client and fully close and reopen the LG TV app. Your saved collection rows and their order are preserved.

## Validation

- All 329 checks in the full browser suite passed, including the actual Featured frontend, native Jellyfin loading callbacks and ElegantFin styles. All 77 final Home/Featured checks also passed after the final focus adjustment, including the additional overflow-action regression.
- Loading checks cover delayed and already-running native requests, empty results, failures, cached Back, account/navigation cancellation and late anchors. Refresh regressions reproduced lost source selection and focus before the fix.
- TV and desktop geometry checks cover thumbnail-only focus, first/last-item scrolling, native section spacing in block and flex layouts, and editor preview proportions. Screenshots were reviewed.
- All 137 unit/API tests and TypeScript checks passed, plus all 89 server assertions on Jellyfin 12.
- All three packages built with zero compiler warnings or errors.

The initial-load wait has an eight-second fallback for stalled or unfamiliar native loading, so an unusually slow section can still arrive later. Installation on the Mac mini and physical-TV verification remain pending.
