# Jellyfin Cinema 0.2.2 — prerelease

This update adds a Home-style preview to the collection row editor so you can see your choices before saving. Install it from the Jellyfin Cinema catalogue or the [v0.2.2 release assets](https://github.com/jampez77/Jellyfin-Cinema/releases/tag/v0.2.2), following the [installation guide](../server.md).

## Changes

- **Collections → Customize collection rows** includes a live preview of the selected draft row. It uses the same artwork cards as Home, showing the title, collection or member artwork, item order and optional ranked number images.
- **Home preview** updates while you edit and marks the row as an unsaved draft. The surrounding labels show which Home rows appear before and after it. Scroll controls let you inspect more cards; item rows preview up to the same 60 members shown on Home.
- Empty selections, loading, unavailable collections and failed requests show useful preview messages. Failed requests can be retried, and missing artwork leaves the card title visible.
- The preview does not save or apply draft settings. **Save rows** applies them to Home; **Cancel** keeps the previous settings.
- Missing-artwork placeholders stay within their cards, leaving preview controls usable.
- Existing Home row settings, browser/account storage and Jellyfin’s own Home preferences are retained. Item ordering remains local to the Home row and does not change the shared collection.

| --- | --- |
| 10.10.7 | 0.2.2.1 |

The plugin GUID, assembly, API routes and archive names are unchanged. Build all three targets with `bash scripts/package-plugin.sh all`. Installation and repository migration are described in the [installation guide](../server.md).

Home preferences remain local to the current server/account/browser. Clearing browser storage removes them.

## Validation

- TypeScript checks and all 80 unit/API tests passed.
- All 200 browser tests passed across the preview and regression suites, including the unmodified Featured frontend. Preview checks cover unsaved drafts, matching saved Home cards, item order, ranking, placement context, asynchronous loading, retry focus, empty/missing artwork and responsive layouts.
- .NET server checks passed for injection, authenticated playback context, script delivery and caching.
- All three server-target packages built with zero warnings/errors; archive integrity, checksums and embedded client hashes passed catalogue validation.
- The collection-card and ranked-item previews were visually checked.

This release has not been installed on the Mac mini or tested with a physical TV remote. Automated fixture checks do not establish real-server playback or hardware compatibility.
