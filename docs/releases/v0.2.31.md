# ScreenHarbour 0.2.31 — prerelease

Your saved trailers now have a home: **Movies → Watchlist**. Films already saved from cinema trailers are retained. Movie and TV-show details offer **Add to watchlist** and **In watchlist**; selecting a saved title removes it. **TV Shows → Watchlist** lists saved whole series without adding every episode. Both library tabs support search, A–Z filters, paging and returning to your selected card.

Add an optional mixed film/show row through **Collections → Customize Home rows → Add Watchlist row** on desktop. Choose its title, position and item order, preview it, then save. For a service-specific row, open **Settings → ScreenHarbour → Streaming services**, select a service and **Add Watchlist row**. It shows saved films and shows matched to that service’s configured UK availability. Existing Home rows and Favourites are unchanged.

Paused cinema trailers now show the **advertised film’s title, synopsis, metadata and artwork** when Jellyfin confirms the movie link. This fixes trailers displaying only a generic “Trailer” title. A late movie mapping is retried, and changing accounts or trailers cannot display a stale result. An unresolvable trailer keeps its own metadata. Button spacing, description fading, initial Skip focus and autoplay remain intact.

## Update

Update **ScreenHarbour**, restart Jellyfin, then fully reload the browser or close and reopen the web-based TV client. Keep **File Transformation** enabled. No uninstall is needed; plugin identity, saved settings and earlier trailer movie saves are preserved.

Use the existing catalogue:

Movie saves retain the private native Watchlist playlist. Whole TV shows are stored separately in Jellyfin’s data directory under `jellyfin-cinema/watchlists/`; include this directory with normal server backups. Each request checks the signed-in account and permitted library items. Watchlist rows remain optional and do not change native Home preferences.

## Validation

TypeScript checks, 205 unit tests and production builds passed. Browser checks cover mixed Home/provider rows, editing and previews, saved-title navigation, search, alphabet filtering, pagination, removal, failure/retry, account changes and returning to an expanded row. Trailer regressions cover delayed advertised-film metadata, queue/account changes, first-play controls, initial Skip focus, autoplay and paused-button spacing with native and ElegantFin styling.

The server verification suite passed **343 assertions on each of Jellyfin 10.10.7, 10.11.0 and 12.0.0**, including authenticated HTTP binding, access restrictions, private playlist reuse, whole-series persistence, concurrent saves, provider filtering and remove consistency.

Browser media transport is simulated. This package has not been installed on the production server or tested on a physical TV.
