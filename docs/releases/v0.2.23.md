# Jellyfin Cinema 0.2.23 — prerelease

Streaming-service rows now use the **collection you choose**, saved by its Jellyfin ID. Collection names are display labels only; renaming a collection or adding Daily/Weekly labels cannot break the link. Existing explicit selections are preserved. Rows that previously relied on automatic name matching need a one-time choice.

On desktop, open a service → **Edit service** → select a row → choose **Collection** → review the preview → **Save changes**. The editor opens that service directly and shows each row's linked collection. **Back to service** returns to its page. No collections are chosen automatically for you, and these editing controls stay off TV service pages.

Under **Automatic catalogue matching**, searchable **Film services** and **TV services** replace numeric provider fields. The authenticated server supplies named UK choices, with separate film/TV mappings, cached results and a retry option. Existing saved mappings are preserved if the full list cannot be loaded.

TV Home service tiles now use one focus ring in the service's accent colour, including custom colours.

Cinema restores the **Watched / Unwatched** tick on movie and episode details for desktop and TV. Episode lists also have individual tick buttons, so an episode can be marked without starting playback. Clearly labelled **Mark series watched** and **Mark season watched** actions apply to the whole series or season.

Changes are saved to the current Jellyfin account using its native watched-status API. Progress, Resume, Play from beginning and Ends at update from Jellyfin's response. Controls keep keyboard and remote focus, failed saves can be retried, and delayed episode reads cannot put old watched badges back after a successful save. Live channels do not offer a watched action.

The faster Home loading and improved service editor from the previous releases are retained.

## Installation

Update from the existing Cinema catalogue, restart Jellyfin, then reload desktop Jellyfin and fully close/reopen the TV app.

## Validation

- TypeScript, 184 unit/API tests, 113 affected browser regressions and server verification checks passed. Packages build for all three supported Jellyfin targets.
- Coverage includes collection-ID binding across renames, explicit selection and preview, named film/TV sources, asynchronous settings recovery, TV tile focus, watched-status writes, bulk propagation, remote season boundaries and delayed episode reads.
- Read-only inspection on the Mac mini confirmed that Netflix's full catalogue returned films and shows, while its trending rows failed because the collection names had changed. No live collection preferences or watch history were changed.
- Desktop service editing, movie details and TV episode-list previews were visually checked. The new package still needs installation and physical LG testing.
