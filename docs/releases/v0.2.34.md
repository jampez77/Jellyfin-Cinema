# ScreenHarbour 0.2.34 — prerelease

**TV arrow navigation now follows the content order on streaming-service pages.** After browsing to the bottom, pressing Up returns through the preceding rows instead of skipping them and jumping to the fixed Back button. The header, section controls and content rows have an explicit navigation order that stays consistent as the page scrolls.

Each horizontal row remembers its selected item when you leave and return with Up or Down. **View all**, **Retry** and **Load more** remain reachable. Hidden and inert controls are excluded from focus navigation.

Full provider grids and the shared library, browse and collection grids now move between adjacent visual rows even when card captions have different heights. This keeps longer titles from sending focus to an unexpected row.

Saved collection rows, streaming-service settings, Watchlists and account preferences are unchanged. Disney+ studio matching and the existing trailer pause-information fixes are retained.

## Update

Update **ScreenHarbour**, restart Jellyfin, then fully reload the browser or close and reopen the web-based TV client. Keep **File Transformation** enabled. No uninstall or settings migration is needed.

## Validation

TypeScript checks, **207 unit tests** and **153 distinct browser checks** passed; one browser check was skipped. The browser runs cover provider navigation, Home, movie/show libraries, browse pages, collections, profile menus, details and season navigation. Five new regressions exercise both arrow keys and Jellyfin remote commands, long scrolled rails, unequal captions, and focus after both intermediate and final catalogue pages load.

The reported Back-button jump was also reproduced with arrow keys in the TV preview before the fix, then the complete Down/Up path was verified after it. **380 server checks passed on each of the Jellyfin 10.10.7, 10.11.0 and 12.0.0 API targets.** All three packages built without warnings or errors. The 10.10 checks used local runtime roll-forward because .NET 8 is not installed.

Browser media transport is simulated. This package has not been deployed to the live server or tested on a physical LG webOS TV during this release work.
