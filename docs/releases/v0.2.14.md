# Jellyfin Cinema 0.2.14 — prerelease

Branded Home tiles open personal provider pages for Netflix, Prime Video, Disney+, Apple TV+, NOW and Paramount+. Configure them in **Settings → Cinema → Streaming services**. Home and provider pages have no editing controls.

## Changes

- Each provider has Films, TV shows, separate trending rows and optional featured artwork. Full rows support pagination and restore selection after visiting an item's details.
- Catalogue rows match your permitted Jellyfin library to **UK subscription availability** from JustWatch through TMDB. They include all matching library titles rather than using trending charts as a catalogue or guessing from studios.
- Trending rows use the existing UK SmartLists/MDBList collections, preserving source order. Collection overrides support other lists or personally curated sources.
- Configure the Home tile row's title, position and service order; show/hide services, rename and arrange provider rows, choose sources and item sorting, and enable numbered poster artwork. Previews show the selected settings before saving.
- Settings sync per Jellyfin account with conflict protection and a quiet offline cache. Library permissions are checked on every catalogue request.
- Availability lookups run in the background, sharing a seven-day metadata cache across services. Progress, missing TMDB metadata and temporarily unavailable data are distinguished from an empty library.

The server reuses its installed TMDB integration. TMDB receives public movie/TV metadata IDs for availability requests; Jellyfin user IDs, media paths and watch history are not sent. See the [provider guide](../provider-homes.md) for sources, ranking semantics and cache behaviour.

## Installation

Update from the existing Cinema catalogue, restart Jellyfin, then reload desktop Jellyfin and fully close/reopen the TV app. Saved collection rows and the plugin identity remain unchanged. The first provider visit may fill gradually while availability is checked.

## Validation

- TypeScript, unit/API checks and browser coverage include provider sources, sorting, settings previews, account isolation, cross-device sync, remote navigation and detail/Back restoration.
- Server checks exercise settings HTTP authentication/revisions, permitted library queries, TMDB parsing, cache persistence, failures and concurrent rate-limit handling on all three build targets.
- The existing preview opens during a real desktop episode. An additional regression uses Jellyfin 12's actual keyboard/input/focus modules with webOS-style key codes and ElegantFin. The reported physical-TV preview failure remains unconfirmed; this release does not claim a new preview fix.
- Provider pages have not been installed or tested on the physical Mac mini/LG TV as part of this release. Browser fixtures and server checks do not establish hardware compatibility.
