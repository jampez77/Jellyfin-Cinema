# ScreenHarbour 0.2.38 — prerelease

**Personalise the loading screen and manage media through Jellyfin's native desktop actions.**

## Loading screen

Open **Settings → ScreenHarbour → Loading screen** to choose **Film projector**, **Clapperboard**, **Film reel**, **Cinema countdown**, **Spotlights** or **Jellyfin logo**. Preview your own title and message, or leave either field blank to hide it. **Save** keeps the choices for your Jellyfin account across devices. **Restore defaults** remains a preview until saved; **Cancel** leaves the saved choice intact.

The last cached choice displays immediately. Refreshing preferences never delays Home content, and return visits keep their existing fast loading behavior. Failed background reads retain the cached choice. The editor reports failed saves and conflicting edits without overwriting another device's settings. The new authenticated settings endpoint is limited to the current account, with atomic storage and conditional revisions.

The optional Jellyfin logo animation uses the project's original icon under CC BY-SA 4.0. Its paths and colours remain unchanged; the complete image is animated with CSS. Source artwork, attribution and the licence are included in each package. Jellyfin does not publish or endorse ScreenHarbour.

## Desktop media management

Desktop administrators get **More** on supported media pages. It opens Jellyfin's native item menu for actions such as **Edit metadata**, **Edit images**, **Refresh metadata** and **Identify**, depending on the item and server. Native forms, permission checks and confirmations remain in control. If the menu cannot open in the current client, ScreenHarbour opens the original item page.

These controls remain hidden in TV display mode and for non-administrator accounts. The ordinary demo does not simulate Jellyfin's native editors; the loading-screen editor and its previews can be tried there with preferences saved in the browser.

## Update

Update **ScreenHarbour**, restart Jellyfin, then fully reload the browser or close and reopen the web-based TV client. Keep **File Transformation** enabled. Existing Home preferences, collection rows, seasonal groups, provider settings and account settings are retained; no migration or reconfiguration is required.
