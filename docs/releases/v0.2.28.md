# ScreenHarbour 0.2.28 — prerelease

This patch fixes Cinema Mode trailer controls from the first trailer. Buttons no longer wait for metadata for the remaining trailers and queued film. **Skip trailer** advances playback without accidentally pausing the next video, and **Add to watchlist** no longer changes the playback state. Both controls remain visible and usable over the pause screen; skipping a paused trailer starts the next queue entry playing.

The extra **Browse** icon is removed in TV layout. Pressing **Down** from the playback controls still opens the in-player browser. Desktop keeps its Browse shortcut.

Home returns to its previous charcoal background. On login only, ScreenHarbour removes its green gradient and opaque background so Jellyfin's or the installed theme's original backdrop can show through. The native user chooser, password form and authentication remain in place.

## Update

Update **ScreenHarbour** through Dashboard → Plugins, restart Jellyfin, then reload the desktop browser or fully close/reopen the web-based TV client. Keep a compatible **File Transformation** plugin enabled. Existing settings and plugin identity are preserved; no uninstall is needed.

## Validation scope

- Type checking, frontend/static-demo builds and all **191 unit tests** passed.
- All **501 browser tests** passed without skips, including cold first-trailer startup, native player pointer/click handling, paused trailer controls, TV remote navigation, Home, Featured and login/theme compatibility.
- All **283 server assertions** passed against each target API. The 10.10.7 checks used explicit .NET 9 runtime roll-forward because .NET 8 is unavailable locally; the plugin remains compiled for .NET 8. The 10.11.x and 12.x checks used their installed .NET 9 and .NET 10 runtimes.

Browser fixtures simulate media playback and server API responses. Server fixtures use a temporary HTTP host rather than a full Jellyfin server. Real-server trailer playback and physical TV remote testing have not been performed for this patch; this remains a server-testing prerelease.
