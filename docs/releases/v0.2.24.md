# Jellyfin Cinema 0.2.24 — prerelease

Home Live TV cards without programme artwork now show their channel logo, fitted inside the card without cropping. Existing thumbnails and lazy-loading programme images keep priority. Native titles, broadcast progress, indicators, playback actions and keyboard/remote focus remain intact. A shared account-scoped channel lookup is cached; Home does not wait for logos before becoming usable. If a channel has no usable logo, the native placeholder remains.

**Playlists** opened from **My Media** or Jellyfin’s navigation now reach Cinema’s existing playlist layout. The plugin recognises the native playlist folder by its collection type and ID, regardless of its name. Playlist contents, saved order, repeated tracks, full-queue playback and Back navigation retain their existing behaviour. Unsupported native filters remain on Jellyfin’s original page.

Movies with a saved playback position now offer **Play from beginning** beside **Resume**. Restart sends a zero playback position without clearing the saved resume point merely by opening the page. TV movie action rows have more vertical space so the Favourite control does not overlap the Resume highlight. Collection and streaming rows use a real end spacer to leave room for the last item’s focus border, including on older TV browser engines.

## Installation

Update through the existing Cinema catalogue, restart Jellyfin, then reload desktop Jellyfin and fully close/reopen the TV app.

## Validation

- TypeScript, all 184 unit/API tests and 94 affected browser regressions passed. Server verification passed, and packages build for all three supported Jellyfin targets.
- Browser coverage includes missing and lazy artwork, logo failures and retries, account changes, Home loading and return focus, playlist entry points and playback, movie resume/restart positions, watched-state updates, and action spacing from 480px to 1920px.
- Row-edge tests cover normal/ranked collection cards, Home service tiles and service-page rows using remote navigation and maximum scroll. Removing trailing padding models the older-scroller issue: the two new cases fail on the previous bundle and pass with the real spacer. The reported physical LG clipping was not reproduced directly.
- TV-layout channel logos and movie controls were visually checked. Installation and physical LG webOS testing remain pending.
