TV Item Layout adds cinematic detail pages for movies, TV shows and Live TV in Jellyfin Web's TV display mode. This is the first release for testing on a real server.

- Movies: backdrop, Play/Resume, trailer icon and playback, favourites, metadata, cast and recommendations.
- TV shows: season sidebar and episode thumbnails with synopses and watch progress. Down from the last episode moves to the next season; Up from the first returns to the previous season's last episode.
- Live TV: horizontal channel/time guide with a prominent banner showing the highlighted programme's artwork and details, including upcoming shows.

## Install

Add this repository under **Dashboard → Plugins → Repositories**:

```text
https://raw.githubusercontent.com/jampez77/Jellyfin-TV-Item-Layout/main/manifest.json
```

Install **TV Item Layout** and a compatible **File Transformation** plugin, then restart Jellyfin. File Transformation's repository is `https://www.iamparadox.dev/jellyfin/plugins/manifest.json`. Enable **TV** display mode in Jellyfin Web and fully reopen the client.

| Server | Plugin version | Archive target |
| --- | --- | --- |
| Jellyfin 10.10.7 | 0.1.0.1 | 10.10.7 |
| Jellyfin 10.11.x | 0.1.0.2 | 10.11.0 |
| Jellyfin 12.x | 0.1.0.3 | 12.0.0 |

For manual installation and troubleshooting, see the [installation guide](https://github.com/jampez77/Jellyfin-TV-Item-Layout/blob/main/docs/server.md).

## Validation and scope

Type checking, 30 unit checks, 32 browser checks, server integration checks and all three target builds pass. Tests use a simulated media library and a temporary HTTP host; real-server playback and physical TV remotes remain to be tested. Native Android TV, Roku and other clients with independent interfaces do not load these layouts. The plugin can run alongside InPlayerEpisodePreview-TV.
