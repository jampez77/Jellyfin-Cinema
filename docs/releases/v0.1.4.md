The Movies library now matches the media layouts, with Jellyfin suggestions, genres, search, title-letter browsing and favourites. The TV guide artwork ends at the top of the schedule instead of extending behind it.

- Browse **All movies**, **Suggestions**, **Favourites** and **Genres** from the Movies page. Suggestions use Jellyfin’s continue-watching, recently-added and recommendation lists.
- Search movie titles and filter by **A–Z** or **#** for numbers and symbols. Genre and favourite results support these filters too.
- Load more films as needed. Returning from a film restores the filters, loaded results and selected card; favourite changes appear when returning to the list.
- Open the existing styled **Collections** page directly from Movies.
- Keeps the guide artwork full bleed at the top, with its lower edge aligned to the schedule on different screen sizes. Channel-logo fallback remains available.
- Preserves the active Jellyfin server in film and collection links so native theme videos can start when a library URL omits the server ID.
