# Jellyfin Cinema 0.2.17 — prerelease

TMDB wording and logos have been removed from service pages, availability row labels, metadata messages and editing hints. Required API attribution is now in one collapsed **Data credits** section at the bottom of **Settings → Cinema → Streaming services**. The provider ID directory remains available there.

Catalogue lookups, saved service configurations, collections and playback continue unchanged.

## Installation

Update from the existing Cinema catalogue, restart Jellyfin, then reload desktop Jellyfin and fully close/reopen the TV app.

| Jellyfin server | Plugin version |
| --- | --- |
| 10.10.7 | 0.2.17.1 |
| 10.11.x | 0.2.17.2 |
| 12.x | 0.2.17.3 |

## Validation

- TypeScript and all 176 unit/API tests passed.
- All 31 affected provider browsing, settings, customisation and navigation browser tests passed. A navigation test now waits for the initial entry's queued hashchange before counting subsequent tab events.
- The cleaned editor and its expandable credits were checked in the browser.
- No server behaviour changed. Packages are built for all three supported Jellyfin targets; this release has not been installed or tested on the physical Mac mini/LG TV during development.
