# ScreenHarbour 0.2.27 — prerelease

Cinema Mode trailers now offer **Skip trailer** and **Add to watchlist**. Skip advances one trailer through Jellyfin’s existing queue and preserves the queued film’s playback selections. Add to watchlist saves the film being advertised to the signed-in user’s private **Watchlist** video playlist, available under **Playlists**.

The watchlist button shows **In watchlist** after saving, prevents duplicate entries and keeps keyboard/TV focus usable during and after the save. Playback changes, account switches and repeated Select presses cannot redirect a save to another film. The advertised film is resolved from Jellyfin’s trailer-owner metadata; an unavailable mapping leaves Add disabled while Skip remains available. These controls support Cinema Mode’s local movie trailers before a film. Standalone trailers, theme videos and custom cinema bumpers retain their normal controls.

Home also leaves the original theme backdrop visible, removing the opaque surface that covered it. Video playlists label their contents **Titles**.

## Update

Update **ScreenHarbour** through Dashboard → Plugins, restart Jellyfin, then reload the desktop browser or fully close/reopen the web-based TV client. Keep a compatible **File Transformation** plugin enabled. Existing settings and plugin identity are preserved; no uninstall is needed.

## Validation scope

- Type checking, frontend/static-demo builds and all **191 unit tests** passed.
- All **490 browser tests** passed without skips, including 13 trailer-control tests, two trailer-demo tests, Jellyfin's native queue/focus-navigation code, Featured and theme compatibility.
- All **283 server assertions** passed against each target API. The 10.10.7 checks used explicit .NET 9 runtime roll-forward because .NET 8 is unavailable locally; the plugin remains compiled for .NET 8. The 10.11.x and 12.x checks used their installed .NET 9 and .NET 10 runtimes.

The server fixtures validate trailer ownership, account boundaries, private playlist creation and duplicate handling. They do not start a full Jellyfin server.

This is a server-testing prerelease. Real-server trailer playback and physical TV remote testing have not been performed for this release.
