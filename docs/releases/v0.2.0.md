# Jellyfin Cinema 0.2.0 — prepared, not published

TV Item Layout is now **Jellyfin Cinema**, reflecting its Home, browsing, collection and playback features. The plugin GUID, assembly filename, API routes and repository URL remain unchanged so current installations can update normally. New catalogue artwork is included in `assets/catalogue/jellyfin-cinema.png` and referenced by the manifest.

## Changes

- Home item titles and subtitles use the same charcoal surface, including focused cards.
- Jellyfin Featured matches the cinematic typography, colours and controls while preserving its own carousel, trailers, settings and remote behaviour.
- Add to collection is available on movie/show details for accounts allowed to manage collections. Choose an existing collection or create one; membership refreshes after saving.
- All movies and All shows are the last library choices.
- Down can open the integrated playback preview when an old/failed standalone preview script is present. Working standalone preview controls keep priority.
- Home's **Customize collection rows** can add a row of chosen collections and separate rows showing individual collections' members. Rows and collection cards can be reordered. Optional ranking uses outlined SVG number images beside posters, with accessible rank labels, rather than adding numbers to titles.
- Collection members retain Jellyfin's configured order across pages. Rankings show positions in that order; no popularity scores are invented.

Home row choices are saved per server/account in this device's browser storage. They do not sync between devices. Custom rows follow native Home sections; native preferences remain in control of those sections. Limits are 12 custom rows, 40 collection cards per row, and 60 members followed by a full-collection action.

## Validation

- TypeScript checks and 73 unit tests passed.
- All 170 browser tests passed, including the unmodified Featured client with fixture APIs.
- .NET server checks passed for injection, authenticated playback context, script delivery and caching.
- All three target packages built with zero warnings/errors; catalogue generation validated their archive integrity and checksums.
- Ranked rows and the catalogue artwork were visually inspected.

The browser tests use simulated Jellyfin data. Physical TV remote testing and live-server deployment are still required. No release has been published or installed by this change.
