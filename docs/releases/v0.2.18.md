# Jellyfin Cinema 0.2.18 — prerelease

Fixes streaming-service tile sizes remaining stale on an already-open Home screen after saving changes. Home now refreshes when the same account's saved settings change in another tab, when a save is confirmed in the current view, and when returning to the tab. A save received during an existing settings request triggers another read instead of being skipped.

The preview still updates immediately while editing; unsaved changes do not affect Home. Settings remain scoped to the Jellyfin account.

## Installation

Update from the existing Cinema catalogue, restart Jellyfin, then reload desktop Jellyfin and fully close/reopen the TV app.

## Validation

- TypeScript and all 176 unit/API tests passed.
- Browser regressions reproduce stale Home dimensions before the fix and verify saved sizes in already-open local and account-synced Home tabs, plus Back and reload.
- All 76 affected provider, Home loading, refresh, account sync, theme lifecycle and navigation browser tests passed, including a save arriving during an older settings read.
- No server behaviour changed. Packages are built for all three supported Jellyfin targets. The new build has not been installed or tested on the physical Mac mini/LG TV during development.
