Home now uses Jellyfin’s existing page with cinematic styling, preserving your Home preferences and the Featured plugin.

- Removed Home’s Back button and redundant Home label.
- Removed the visible Paused label and decorative pause icon. Media artwork, details and Live TV channel names remain.
- Kept the native Home section choices and order, user/device overrides, library ordering and exclusions, Continue listening/reading, Next up preferences and library destinations.
- Kept [Jellyfin Featured](https://github.com/spkesDE/jellyfin-featured-plugin) in its original Home container. Its carousel, personalization, trailers and remote controls remain controlled by Featured; keep that plugin enabled.

The previous replacement Home queried a fixed set of rows and hid the native page, bypassing preferences and covering Featured. This release removes that replacement and applies scoped styling without moving or recreating native Home content.
