# ScreenHarbour 0.2.32 — prerelease

Home and streaming-service pages now show **Watchlist rows only when they contain items**. Empty service Watchlist section buttons are hidden too. Your saved row settings remain intact, and rows appear when titles are added or availability matches arrive. The row editor retains its empty/error feedback. Service browsing also removes the library-wide “titles need matching metadata” notice.

Paused trailers can now show their **advertised film’s title, synopsis, metadata and artwork even when Jellyfin reports a queue containing only that trailer**. Metadata lookup checks the current playback and permitted movie independently of cinema-mode controls. This fixes the missing film information observed with Mayday. Skip and Add to watchlist retain their existing cinema-mode eligibility, initial focus, spacing and autoplay behaviour.

Service Watchlist rows still require the saved title’s exact edition to match the service’s configured UK availability. Remakes and originals have separate entries; studio ownership does not determine membership. This release does not change those matching rules.

## Update

Update **ScreenHarbour**, restart Jellyfin, then fully reload the browser or close and reopen the web-based TV client. Keep **File Transformation** enabled. No uninstall is needed; plugin identity, saved settings and Watchlist entries are preserved.

## Validation

TypeScript checks and **207 unit tests** passed. Browser checks cover empty/loading/error Watchlist rows, automatic reappearance after matching, focus recovery after removal, provider navigation, Home row customization, and playback with a single-trailer queue. Pause-screen and trailer regressions verify metadata, account/queue changes, first-play controls, initial Skip focus, autoplay and paused-button spacing with native and ElegantFin styling.

The server verification suite passed **356 assertions on each of Jellyfin 10.10.7, 10.11.0 and 12.0.0**, including authenticated trailer metadata, playback identity, native movie access restrictions and unchanged cinema-only action eligibility.

Browser media transport is simulated. This package has not been installed on the production server or tested on a physical TV.
