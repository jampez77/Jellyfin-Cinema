# Jellyfin Cinema 0.2.10 — prerelease

Fixes the first-use Home sync failure introduced in 0.2.9 and removes Home’s background-sync warning. Install from the Jellyfin Cinema catalogue or the [v0.2.10 release assets](https://github.com/jampez77/Jellyfin-Cinema/releases/tag/v0.2.10), following the [installation guide](../server.md).

## Changes

- Jellyfin’s JSON configuration omits null properties. An account with no saved server rows therefore received `{}` instead of the explicit empty-settings response, and Cinema rejected it as invalid. The response now explicitly includes those nullable fields, allowing the existing desktop rows to migrate and the editor to load. Existing saved rows, account isolation and revision checks are preserved.
- Home no longer displays a sync-failure message or **Retry row sync** button. It keeps any cached rows and retries when the app returns to the foreground or during the normal background refresh.
- The collection editor still reports unsuccessful loads, saves and conflicting edits. An unsuccessful save retains its draft and never claims success.

## After installing

Restart Jellyfin, reload the original desktop browser and open Home once. Existing rows can then migrate to the server. Fully close and reopen the TV app using the same account. There is no need to recreate your rows or clear browser storage.

## Validation

- All 41 Home/editor/navigation browser checks passed, including quiet sync failures with and without cached rows, automatic recovery, migration, conflicts and failed saves.
- All 137 unit/API tests and TypeScript checks passed.
- All 89 server assertions passed on each supported Jellyfin target, including 11 new checks with the actual JSON configuration over HTTP. The new first-use regression failed before the fix and passed afterwards. Jellyfin 10.10.7 verification uses its net8 target and packages with .NET 9 runtime roll-forward.
- All three packages built with zero compiler warnings or errors.

The regression checks exercise Jellyfin’s own JSON options over a real local HTTP controller endpoint, alongside browser sync/editor coverage. Installation on the Mac mini and physical-TV verification remain pending.
