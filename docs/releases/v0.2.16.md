# Jellyfin Cinema 0.2.16 — prerelease

Home now has a fixed animated cinema loader and restores your previous position after loading. Streaming services gain tile sizing, optional name labels, fully editable services and three UK broadcaster presets.

## Changes

- A projector animation stays centred in the viewport while Home loads, including when returning to a lower row. Reduced-motion preferences show static artwork. The existing 3.5-second fallback remains, and other pages/native Favourites remain usable.
- Returning within the same session restores the account's selected card, vertical scroll and horizontal row offsets after rows settle. New navigation input takes priority.
- Settings → Cinema → Streaming services includes tile size (70–150%), name labels, custom services, editable names/logos/colours, service and row order, source IDs and subscription/free/ad-supported availability choices. Live previews use unsaved drafts; Save, Cancel, remove and restore controls are explicit.
- BBC iPlayer, ITVX and Channel 4 presets match UK free/ad-supported offers against permitted library titles. They begin with Films and TV shows. Use selected collections for additional/trending rows; no new external chart subscription is created.
- Existing provider choices migrate to the expanded settings format; the three new services are appended unless the saved service list is explicitly empty. Previous catalogue subscription matches remain available while the cache acquires the new offer categories.
- Custom services and draft previews retain native account/library permissions. Older clients cannot overwrite expanded settings with the old format.

## Installation

Update from the existing Cinema catalogue, restart Jellyfin, then reload desktop Jellyfin and fully close/reopen the TV app. Configure services under **Settings → Cinema → Streaming services**. Existing collections and SmartLists refresh schedules are unchanged.

## Validation

- TypeScript, all 176 unit/API tests and the full 408-test browser suite passed. The 10 loader/return-position regressions also passed twice in a focused run.
- All 210 server assertions passed for each supported Jellyfin API target, including actual HTTP preview binding, migration, per-account access, offer categories and old-cache preservation. The .NET 8 target used .NET 9 runtime roll-forward in this development environment.
- All three release packages built without warnings. DLL identities, target frameworks and embedded client resources were checked.
- Desktop, TV and narrow layouts were reviewed, including custom artwork fallback, long names, fixed loading art and reduced motion.

This release has not been installed or tested on the physical Mac mini/LG TV during development.
