# Jellyfin Cinema 0.2.6 — prerelease

This update brings Search, Settings, login and ordinary folder libraries into the Cinema theme, adds administrator Dashboard shortcuts and makes passwordless public profiles quicker to switch between. Install it from the Jellyfin Cinema catalogue or the [v0.2.6 release assets](https://github.com/jampez77/Jellyfin-Cinema/releases/tag/v0.2.6), following the [installation guide](../server.md).

## Changes

- **Search and Settings** keep their native controls and actions with Cinema colours, spacing, cards and focus states. The signed-in administrator gets a Dashboard shortcut in Settings and the avatar menu; permission is checked again when selected.
- **Switch profile** shows the server’s public profiles. Selecting an existing passwordless account signs out the old session and opens the new account’s Home directly. Protected accounts and hidden profiles retain native sign-in. Cinema does not store additional credentials or weaken password requirements.
- The signed-out **login screen** gains larger profile cards, matching password forms and themed Quick Connect/error dialogs in TV mode. Jellyfin still controls authentication and the saved device layout.
- An older **Recordings** library can differ from the server’s current DVR library. Ordinary folder libraries now get Cinema headings, controls and cards while retaining their own contents and native filters. The current DVR folder continues to use Cinema’s recordings view.
- Returning to an ordinary folder after visiting another page reapplies its theme. Cached native pages and account/layout changes release the appropriate styling.

## Validation

- 261 browser checks passed, including Featured, the actual Jellyfin 12 login controller and music templates, and the active ElegantFin stylesheet. Checks cover native actions, narrow layouts, permission revocation, profile switching, cancellation and delayed responses.
- 107 unit/API tests, TypeScript checks, the client build and server integration checks passed.
- All three server packages built with zero warnings and errors.
- The native recording routes and theme were inspected on Jellyfin 12. Search, Settings, profile chooser, login and historical recording-folder layouts were reviewed visually.

This release has not yet been installed on that server or tested with a physical TV remote. Login and switching checks use simulated server responses; they do not establish a live-server session handover or real playback.
