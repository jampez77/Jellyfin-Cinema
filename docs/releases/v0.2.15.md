# Jellyfin Cinema 0.2.15 — prerelease

This release fixes empty provider trending rows, Back navigation inside streaming services, and the staggered appearance of custom Home rows.

## Changes

- Automatic trending discovery recognises the `[Smart]` suffix added by SmartLists. The existing UK chart collections, their members and their source order are preserved. Ambiguous collection names still require an explicit override.
- Back from a provider page returns to the main Home screen. Changing provider tabs does not add extra history entries; returning from a movie or show's details still restores the provider tab and selected item.
- Native Home sections, streaming-service tiles and collection rows coordinate their initial reveal. A bounded fallback keeps Home usable if loading stalls. Background refreshes keep existing content visible.

## Installation

Update from the existing Cinema catalogue, restart Jellyfin, then reload desktop Jellyfin and fully close/reopen the TV app. Saved settings and collections remain unchanged.

## Validation

- Regression coverage includes SmartLists collection names for all six providers, provider tab/Back navigation, details return selection and coordinated Home loading.
- TypeScript and 169 unit/API tests passed. The full 387-test browser suite passed; after the final account-focus adjustment, all 94 affected Home, provider and profile checks passed, including two new account-isolation regressions.
- All 164 server checks passed for each of the three API targets. The .NET 8 target used .NET 9 runtime roll-forward in this development environment.
- The live Mac mini's collection names were inspected to confirm the discovery failure. This release has not been installed or tested on the physical LG TV as part of development.
