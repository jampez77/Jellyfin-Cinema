# ScreenHarbour 0.2.33 — prerelease

**Disney+ now includes library titles from recognised Disney studios even before or between streaming releases.** Films such as live-action Moana qualify through their existing Jellyfin studio metadata instead of waiting for UK streaming availability. The same membership rule applies to Disney+ Films, TV shows and mixed Watchlist rows, including full grids and previews.

The additional matching covers Disney, Pixar, Marvel Studios, Lucasfilm, 20th Century/Fox, Searchlight and related television production labels, including historical names. It uses exact normalised studio names. Recognised studio titles appear immediately without an availability request or a TMDB ID; licensed titles continue to qualify through the configured UK streaming offers.

This follows the Disney+ selection separately for film and TV sources, including custom or renamed service pages. Explicit collection rows keep their selected contents. Native library access, parental restrictions and saved Watchlist membership still apply before matching. Your existing Moana studio metadata needs no correction when it includes Walt Disney Pictures.

Empty Watchlist rows remain hidden. The Mayday pause-screen information fix from 0.2.32 is retained.

## Update

Update **ScreenHarbour**, restart Jellyfin, then fully reload the browser or close and reopen the web-based TV client. Keep **File Transformation** enabled. No uninstall or settings migration is needed.

## Validation

TypeScript checks, **207 unit tests** and **46 provider/browser checks** passed. Server regressions verify both animated and live-action Moana, films and series, mixed Watchlists, studio aliases and false positives, current-user restrictions, per-type mappings, stable sorting/paging and matching without streaming availability.

**380 server checks passed on each of Jellyfin 10.10.7, 10.11.0 and 12.0.0 API targets.** The 10.10 package compiles for .NET 8; local verification uses .NET 9 runtime roll-forward because .NET 8 is not installed. Moana's Walt Disney Pictures metadata was also verified read-only on the live server.

Browser media transport is simulated. This package has not been installed on the production server or tested on a physical TV.
