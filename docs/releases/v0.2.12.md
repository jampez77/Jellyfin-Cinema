# Jellyfin Cinema 0.2.12 — prerelease

Home keeps its Cinema styling when Jellyfin and third-party styles arrive later. Playback fixes also cover desktop Live TV and navigating the video controls. Install from the Cinema catalogue or the [v0.2.12 release assets](https://github.com/jampez77/ScreenHarbour/releases/tag/v0.2.12), following the [installation guide](../server.md).

## Changes

- Home backgrounds, headings, card captions and Featured buttons retain Cinema's theme after native and ElegantFin styles load. If a native page update removes Cinema's Home marker, it is restored without rebuilding rows or moving focus.
- Down opens the in-player episode browser at the bottom of the playback controls. Moving down from the player header or seek controls keeps native navigation available.
- Resumable episodes offer **Play from beginning** beside **Resume**.
- Desktop Live TV can dispatch playback through Jellyfin's native React item container when its legacy custom element is unavailable. The native playback pipeline still handles streaming.
- Loaded Home collection contents refresh every minute while visible and when focus returns. Membership and order changes appear even when row settings are unchanged. Failed requests retain the last loaded items; unchanged responses leave the rows and focus alone.
- Collection-row customization is available on the desktop Collections page. TV displays saved account rows without the editing button.
- Removed navigation legends and instructional prompts from the theme. Action labels, accessibility labels and necessary error messages remain.

## After installing

Restart Jellyfin, then reload the desktop client and fully close and reopen the LG TV app. Saved collection rows and their order are preserved.

SmartLists source refreshes are separate from Cinema's Home refresh. With the documented staggered daily setup, adding a movie to the library does not immediately update its trending collection. Wait for the schedule or refresh that SmartList individually while SmartLists is idle. See the [platform trending setup](../platform-trending.md).
