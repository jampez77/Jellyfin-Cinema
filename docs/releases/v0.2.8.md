# Jellyfin Cinema 0.2.8 — prerelease

The Cinema theme now works in Jellyfin Web’s **desktop display mode**, keeping the same design as TV. Install from the Jellyfin Cinema catalogue or the [v0.2.8 release assets](https://github.com/jampez77/Jellyfin-Cinema/releases/tag/v0.2.8), following the [installation guide](../server.md).

## Changes

- Home, Featured styling, collection rows and editor, libraries, movie/episode details, music, recordings and Live TV now use Cinema in desktop mode. Existing per-account Home rows carry over in the same browser.
- Search, Settings, native login and the **Who’s watching?** profile chooser also work on desktop. Eligible passwordless accounts use the same guarded native switch; administrator Dashboard links retain their permission checks.
- Music playback controls, the Now playing queue, video pause artwork and in-player browsing share the theme on desktop. The existing compact audio player remains accessible over Cinema pages, with room reserved for its height and native mouse, slider and keyboard controls.
- Jellyfin’s actual display mode stays unchanged. Desktop keeps native desktop controls; mobile and unrecognised layouts retain their native pages. Changing layouts releases the appropriate Cinema views and player controls.
- The local preview supports `?layout=desktop` for comparing the layouts.
