# ScreenHarbour 0.2.42 — prerelease

**Seasonal rows now have themed ranking images.**

Ranked Halloween and Christmas item rows now use number artwork that matches their frame style. The numbers remain scalable images beside the posters, retain the existing size and ordering, and do not depend on installed fonts or external image services.

In **Collections → Customize Home rows**, edit a seasonal sub-row. Enable **Ranked artwork** in **Content**, then open **Appearance → Rank number style**:

- **Match frame style** follows the row’s chosen frame artwork; this is the default.
- **Standard numbers** keeps the original outlined numbers.
- **Illustrated** uses Halloween cobwebs and bats or Christmas holly and festive colours.
- **Playful / family** uses pumpkins or candy stripes and icing.
- **Textured** uses dimensional stone/metal or gold and snow finishes.
- **Nightmare** adds cracked bone and dark-red details for Halloween only.

The Home preview shows each choice before saving. Choosing **Normal** keeps the standard row and original number images. Number styles can be changed separately from backgrounds, frames and doors. Ordinary rows retain their existing appearance.

Saved number-style choices sync with the seasonal row. Older clients may read the settings, but cannot save over a row containing number-style choices they do not understand; fully reopen those clients after updating.
