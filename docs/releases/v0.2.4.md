# Jellyfin Cinema 0.2.4 — prerelease

This update fixes Home navigation and the collection editor, and restores estimated finish times on movie and episode details. Install it from the Jellyfin Cinema catalogue or the [v0.2.4 release assets](https://github.com/jampez77/Jellyfin-Cinema/releases/tag/v0.2.4), following the [installation guide](../server.md).

## Changes

- **Up** navigation moves between native Home sections, custom collection rows and platform collection tabs without looping back into the same rows.
- Missing-artwork placeholders stay inside their thumbnails in the collection editor. A collection or item without artwork can no longer cover the surrounding editor controls with its background.
- **Ends at** returns beside movie and episode ratings, including for the episode selected in the series hero. It uses the current local clock and remaining runtime for **Resume**, or the full runtime when **Play** starts a watched title from the beginning. The estimate updates when its displayed finish minute changes and is omitted without a playable movie/episode and valid duration.
- Existing collection-row selections, tabs, sorting, ranked artwork and Home placement are retained.

The plugin GUID, assembly, routes and archive names are unchanged. Build all three targets with `bash scripts/package-plugin.sh all`.

Home preferences remain local to the current server/account/browser. The estimated finish time depends on the client clock and the runtime/playback position supplied by Jellyfin.

## Validation

- 219 browser tests and 84 unit/API tests passed, including the real Featured plugin fixture.
- The Home navigation and missing-artwork regressions were reproduced before their fixes. Keyboard arrows and remote commands now traverse the affected Home layout without looping.
- Finish-time checks cover resume/restart, the selected episode, clock updates, midnight rollover, locale formatting and timer cleanup. The movie metadata and collection editor were also reviewed visually.
- TypeScript checks, client build and server integration checks passed. All three server packages built with zero warnings and errors.

The original navigation and editor failures were reproduced in the live Jellyfin browser. This fixed release has not yet been installed on that server or tested with a physical TV remote; automated checks do not establish real-server playback or hardware compatibility.
