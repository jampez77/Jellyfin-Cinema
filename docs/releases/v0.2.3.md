# Jellyfin Cinema 0.2.3 — prerelease

This update adds optional collection tabs to Home rows. Keep separate collections under one row title, such as Movies and Shows for a streaming platform, and switch between them without adding another Home row. Install it from the Jellyfin Cinema catalogue or the [v0.2.3 release assets](https://github.com/jampez77/Jellyfin-Cinema/releases/tag/v0.2.3), following the [installation guide](../server.md).

## Changes

- Collection item rows support up to six tabs. Each has an editable label, source collection and independent item order, including manual ordering. Tabs can be moved left or right, with the first tab opening by default.
- Tabs work with ranked artwork, the live Home preview, row placement and TV navigation. Numbered artwork follows the selected tab's visible item order.
- Existing single-collection rows and saved preferences are retained. Tabs use ordinary Jellyfin collections; an external list plugin is optional.
- A [UK platform trending guide](../platform-trending.md) explains how to build six rows for Netflix, Prime Video, Disney+, Apple TV+, NOW and Paramount+, each with separate Movies and Shows tabs. SmartLists and MDBList can maintain their source collections using weekly UK JustWatch charts and daily refreshes.

## Build targets

| Jellyfin server | Plugin version |
| --- | --- |
| 10.10.7 | 0.2.3.1 |
| 10.11.x | 0.2.3.2 |
| 12.x | 0.2.3.3 |

Cinema's plugin GUID, assembly, routes and archive names are unchanged. Build all three targets with `bash scripts/package-plugin.sh all`. The optional SmartLists setup documented for platform charts requires SmartLists 12.0.3.0 or newer on Jellyfin 12; ordinary collection tabs work without it.

Home preferences remain local to the current server/account/browser. Tab sorting changes the Home display only. Ranked number images show visible-library positions and do not preserve gaps for chart titles missing from the library.

## Validation

TypeScript checks, 82 unit/API tests, all 209 browser tests and the .NET server checks passed. All three plugin targets built with no warnings or errors. Browser checks include tab-specific ordering, preview parity, remote navigation, Back restoration, empty/error states and late-response focus handling.

Physical TV remote testing has not been performed for this release. Automated fixture checks do not establish real-server playback or hardware compatibility. The platform-chart guide documents the SmartLists batch-order workaround; source availability and library matches depend on your server and MDBList access.
