# Jellyfin Cinema 0.2.13 — prerelease

Restores the in-player preview shortcut in layouts that place the seek slider below the playback buttons. Install from the Cinema catalogue or the [v0.2.13 release assets](https://github.com/jampez77/ScreenHarbour/releases/tag/v0.2.13), following the [installation guide](../server.md).

## Changes

- Down opens the episode/film/channel preview from the bottom focusable playback control, including the seek slider in ElegantFin's player layout.
- Moving down from the player header or an upper control continues through Jellyfin's native controls before opening the preview.
- Native focusability is respected when finding the bottom control, so hidden or unfocusable controls do not block the shortcut.

## After installing

Restart Jellyfin, then reload the desktop client and fully close and reopen the LG TV app. The plugin identity, catalogue URL and saved collection rows are unchanged.
