# ScreenHarbour 0.2.35 — prerelease

**Seasonal collections can now appear automatically on Home.** In desktop mode, open **Collections → Customize Home rows → Add seasonal group**. Give the group one Home position, then add named sub-rows such as Halloween or Christmas. Choose collections or collection items, or a Watchlist, and set each sub-row's start and end month/day.

Dates repeat every year and include both endpoints. October 1–31 shows Halloween throughout October; December 1–January 6 supports Christmas across New Year. Visibility uses the viewing device's local calendar, with checks at midnight and when a sleeping client returns. Overlapping sub-rows appear together in their configured order.

Only active sub-row names and cards appear on Home. The group itself has no heading, and an inactive group creates no empty section or spacing. Sub-rows retain the existing collection choices, tabs, ranked artwork, custom ordering and preview. The preview works outside the configured season too. A group can contain up to 12 sub-rows.

**Shuffle on load** is available under **Item order** for any ordinary or seasonal sub-row. Each Home visit gets a fresh random order; background refreshes keep existing items steady and append newly available ones. Saved ordering and Jellyfin's underlying collection are unchanged. Turning shuffle off restores the chosen order. Back navigation keeps the previously selected item reachable even when it would fall outside the first 60 shuffled cards.

Dates, content choices and shuffle settings sync through the existing Jellyfin account settings. Existing rows, provider settings, plugin identity and storage paths are retained. Older cached editors cannot overwrite settings containing seasonal groups or shuffle: fully reopen clients after updating.

## Update

Update **ScreenHarbour**, restart Jellyfin, then fully reload the browser or close and reopen the web-based TV client. Keep **File Transformation** enabled. No uninstall or manual settings migration is needed.

## Validation

TypeScript and 215 unit checks passed. **114 browser checks passed**, with 20 optional external-source checks skipped because their audited checkouts were unavailable. Browser regressions cover seasonal editing, shared placement, tabs and ranks, date boundaries, New Year ranges, automatic midnight changes, inactive groups without requests or placeholders, delayed season handovers, shuffled refreshes and restored focus. Server validation and authenticated HTTP round trips passed **446 checks on each Jellyfin 10.10.7, 10.11.0 and 12.0.0 API target**, including protection against older editors erasing new settings. The 10.10 checks used local runtime roll-forward because .NET 8 is not installed.

Browser media transport is simulated. This package has not been deployed to the live server or tested on a physical LG webOS TV during this release work.
